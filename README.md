# Face Attendance System

## 📌 Overview
A Python-based project that uses face recognition to mark attendance automatically.

## ⚙️ Features
- Face detection and recognition
- Attendance logging in database
- Simple and user-friendly interface

## 🚀 Technologies Used
- Python
- OpenCV
- MySQL

## 📂 How to Run
1. Clone the repository
2. Install dependencies
3. Run `main.py`
